# 风险识别技能

## 目标
基于工具拉取到的**事实数据**（画像、学业成绩、心理量表、出勤），对学生做多维风险研判，输出风险等级、主因类型与根因分析。

## 数据采集顺序
1. `get_student_profile` —— 基础档案（年级、专业、家庭经济、辅导员备注）
2. `get_academic_history` —— GPA 趋势、挂科课程、学分完成度
3. `get_mental_indicators` —— 心理量表分数与等级（SCL-90 / PHQ-9 等）
4. `get_attendance` —— 出勤率、缺勤模式（连续缺勤 > 散点缺勤）

数据缺失时不要臆造：在 `key_indicators` 标注"该维度数据缺失"，并相应下调判定置信度。

## 风险等级判定标准
- **high**：多维度同时恶化，或单一维度极度异常（GPA 骤降 ≥30%、心理量表红色预警、连续缺勤 ≥2 周）
- **medium**：单一维度明显异常，或多维度出现轻微恶化的叠加信号
- **low**：存在潜在风险信号但尚未形成趋势（如单科预警、出勤率轻微下滑）
- **none**：各维度数据正常，无风险信号

## 风险类型
学业滑坡 / 心理健康预警 / 出勤异常 / 经济困难影响 / 社交孤立 / 综合风险（多类叠加时取主导类型，并在分析中点明次要类型）

## 归因要点
- 区分**相关**与**因果**：成绩下滑可能是结果而非原因，追问上游（心理、经济、家庭变故）
- 经济困难、单亲、留守等敏感标签只能以**中立、关怀**视角作为背景因素，**不得**作为歧视性判定依据
- 量化优先：根因分析引用具体数值（"GPA 从 3.2 降至 2.1"），而非笼统判断

## 输出
风险部分必须包含：`risk_level`、`risk_score`(0-100)、`primary_risk_type`、`root_cause_analysis`、`key_indicators`（带数值）、`urgency_reason`。
