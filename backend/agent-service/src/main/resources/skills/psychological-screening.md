# 心理健康初筛技能

## 定位与边界
本技能用于**初筛与转介建议**，**不**做临床诊断。任何疑似中重度心理危机，结论必须是"建议尽快转介专业心理咨询/医疗机构"，而非给出诊断标签或治疗方案。

## 量表解读
- 调用 `get_mental_indicators` 获取分数与等级；必要时 `search_psychology` 检索量表说明与常模
- 常见量表：SCL-90（90 项症状自评）、PHQ-9（抑郁）、GAD-7（焦虑）、PSS（压力知觉）
- 关注**单项高分**（如 PHQ-9 第 9 题自伤意念）即使总分不高也属红色信号

## 预警分级
- **红色（立即）**：自伤/自杀意念、明确的危机表述、量表重度区间 → 立即转介 + 通知辅导员/心理中心，干预方案 `urgency` 拉满
- **黄色（关注）**：中度区间、情绪/睡眠/食欲持续异常 → 安排谈心 + 1-2 周内复评
- **绿色（常规）**：轻度或正常 → 纳入常规关怀，不过度标签化

## 谈心提纲要点
- 开放式提问、非评判倾听，先共情再了解
- 评估社会支持系统（家庭、室友、朋辈）
- 留意保护性因素（求助意愿、稳定关系、未来目标）

## 隐私与伦理
心理数据属 EXTREME 敏感级。分析中只陈述与干预必要相关的信息，不渲染细节、不传播；输出引用 `search_psychology` 结果时标注来源。
