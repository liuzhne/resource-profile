# 干预方案设计技能

## 设计原则
1. **可执行**：每条行动有明确动作、责任人、时限，避免"加强关注"之类空话
2. **分层**：立即行动（1-2 周内见效）与长期计划（1-6 个月）分开
3. **对症**：行动直接对应 `primary_risk_type` 与 `key_indicators`，一一可追溯
4. **循证**：必要时 `search_cases` 检索相似历史案例、`search_policies` 检索可调用的校内资源/政策

## 责任人分工
- **辅导员**：谈心、家校沟通、日常跟进、协调资源
- **班主任**：学业关注、课堂表现观察、同伴互助安排
- **心理咨询师**：心理疏导、危机干预、复评（红黄信号必配）
- **学业导师**：选课/补考/学业规划、学习方法辅导

## 方案结构
- `immediate_actions`：[{action, owner, deadline}]，覆盖最紧迫的 2-4 项
- `long_term_plan`：[{goal, milestones[], horizon}]，设可衡量里程碑
- `talk_outline`：辅导员谈心提纲（开场—了解—共情—引导—约定）
- `resources`：可调用的具体资源（心理中心、助学金、学业辅导中心、朋辈帮扶）
- `references`：方案依据（案例/政策/理论，带来源说明）

## 经济困难类专项
经济信号为主导时，优先 `search_policies` 查助学金/勤工助学/临时困难补助路径，把申请动作写进 `immediate_actions`，避免只做心理疏导而不解决现实困境。

## 红线
方案不得包含歧视性、贴标签或侵犯隐私的措施；涉及家庭沟通时注明"需征得学生知情/同意"的边界。
